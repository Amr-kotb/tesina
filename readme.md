# Tesina Multimediale – Sito Web con Mini AI

## Titolo del progetto
"Linguaggi di programmazione a confronto: dal C a Python, passando per React e Flutter"

---

## Obiettivo del progetto

Realizzare un sito web completo e funzionante che integri una mini AI (basata su Python) in grado di rispondere a domande relative ai linguaggi di programmazione, fornendo piccole spiegazioni chiare e mirate.

L'AI e il cuore pulsante del progetto, sviluppata in Python per la sua semplicita, potenza e adattabilita nell'ambito dell'AI e del machine learning.

---

## Tecnologie utilizzate

| Linguaggio | Ruolo nel progetto |
|------------|---------------------|
| HTML       | Struttura e scheletro delle pagine web |
| CSS        | Stile, layout e responsivita |
| JavaScript | Interattivita e gestione delle chiamate all'AI |
| Python     | Backend dell'AI (elaborazione domande e risposte) |

---

Spiegazione generale dei linguaggi di programmazione piu diffusi, con focus sui top 3:
