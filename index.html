I linguaggi piu' importanti della storia

Esistono oltre 700 linguaggi di programmazione, ma questi tre hanno plasmato l'informatica moderna. Clicca su ogni card per approfondire.

C

1972 | Dennis Ritchie (Bell Labs)

Il "padre" dei linguaggi moderni

Il C e' un linguaggio di programmazione procedurale, noto per la sua efficienza e il controllo diretto sulla memoria. Sviluppato per scrivere il sistema operativo UNIX.

CompilatoSystem ProgrammingLow Level
Performance: 95%TIOBE Index: #2

Python

1991 | Guido van Rossum

Il linguaggio piu' versatile del momento

Python si distingue per la sua sintassi chiara e leggibile, ideale per principianti e professionisti. Dominante nell'AI, Data Science e sviluppo web.

InterpretatoAI & Data ScienceHigh Level
Popolarita': 98%#1 su GitHub

Java

1995 | James Gosling (Sun Microsystems)

Write Once, Run Anywhere

Java ha introdotto la JVM, permettendo ai programmi di funzionare su qualsiasi piattaforma. Standard per applicazioni enterprise e Android.

JVMEnterpriseOOP
Adozione Enterprise: 85%3+ miliardi di dispositivi
